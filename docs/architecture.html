chess_rl architecture

Two packages stacked on python-chess. chess_env turns a board into a fixed tensor and a 4672-way legal-move mask. chess_gan trains a residual policy with an R3GAN critic; because moves are discrete, the generator step is PPO.

entry training networks data environment
1 · Entry points · what you run
Declared as scripts in pyproject.toml · train_modal wraps train.py on a GPU
chess_env/play.py
Terminal game. Sides: human, random, expert, gan. Loads a checkpoint through GanAgent.
chess_gan/train.py
Local training loop. Owns the iteration: buffer, self-play, D step, PPO, EMA, checkpoint.
chess_gan/eval.py
Score a checkpoint vs random and the greedy expert using play_episode.
chess_gan/train_modal.py
Modal GPU job. Calls train_from_kwargs, stores models/r3gan.pt on a Volume.
2 · chess_gan · policy + critic
R3GAN imitation of play, plus game outcome in the reward
nets.py
Generator: π(a|s) + V(s), illegal logits → −∞. Discriminator: D(s,a) scalar. Shared residual CNN, no BatchNorm.
agent.py
Load models/r3gan.pt (EMA weights). Callable policy for play_episode / play.py.
rollout.py
Generator vs itself via play_episode. Stores boards, masks, actions, logp, values, game returns.
ppo.py
Clipped PPO on the generator. Reward = game outcome + gan_coef × tanh(D).
losses.py
Relativistic pairing GAN + zero-centered R1/R2 gradient penalties on D.
features.py
Action → two 8×8 from/to planes. Concatenate with board → (22, 8, 8) for D.
buffer.py
Replay of real (board, action, mask). Seeded by expert, topped up with winning self-play plies.
expert.py
ε-greedy 1-ply material + piece-square teacher. The first “real” distribution for D.
3 · chess_env · the game
One policy plays both colors · player-relative view
episode.py
play_episode(white, black) runs a full game. Episode.return_for_side labels every ply with +1 / 0 / −1. random_policy lives here.
env.py · ChessEnv
Gymnasium wrapper. reset / step. obs = {board, action_mask}. Sparse step reward; illegal move → −1 and end.
encode.py
Board → (20, 8, 8) float32. Pieces, castling, ep, colour, fifty-move, repetition. Black-to-move boards are mirrored.
actions.py
AlphaZero map 8×8×73 = 4672. encode_move / decode_action / action_mask. Always in the side-to-move’s view.
4 · One training iteration · train.py
Left to right, every loop. Modal runs this same function on a GPU.

1 Fill real data

  • Start: expert.py games → buffer.py
  • Each iter: more expert games
  • Winning self-play plies join the buffer (self-imitation)

2 Self-play

  • rollout.py wraps Generator as a policy
  • Calls play_episode on the env
  • Illegal logits already masked in nets.py

3 Update D

  • Real (s,a) from buffer, fake from rollout
  • features.py packs (22, 8, 8)
  • losses.py relativistic D + R1/R2

4 Update G, save

  • Reward = outcome + tanh(D)
  • ppo.py steps the Generator
  • EMA copy → models/r3gan.pt → agent.py
